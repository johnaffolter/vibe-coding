# si-elements (vendored)

A copy of `packages/si-elements` from the Superintelligence Homepage repository: one portable descriptor for any
element (properties, keys and surrogates, grain, relationships with direction and cardinality, constraints,
lifecycle, series, aliases, tags) with SHACL, N-Quads, JSON-LD, row checks and the relationship DAG. No dependencies.
Keep it in step by copying `index.js` and `element.schema.json` from there.
